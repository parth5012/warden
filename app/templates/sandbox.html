SandboxPort Isolation Architecture (Gourav's Component)

Per INTEGRATION_GUIDE.md, tool execution is strictly isolated via the SandboxPort interface.
High-risk actions (run_shell, run_code) run inside ephemeral subprocesses bounded by Linux cgroups v2 resource quotas or isolated Docker containers with non-root UID 1000.
All sensitive environment variables (API credentials, connection strings) are sanitized prior to execution fork to prevent unauthorized extraction.
